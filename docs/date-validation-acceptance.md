# 日期合理性校验验收

日期：2026-10-15。

## 本次规则

- 出厂日期、启用日期、设备制造日期共用校验入口。
- 不存在的月份或日期、非闰年的2月29日、Excel虚构日期1900-02-29均为阻断错误。
- 年份不能晚于当年；当年按北京时间计算，每次任务开始时固定一次，跨年自动更新。
- 用户没有指定“距离当年差异较大”的年限；本次暂定超过100年阻断，代码集中使用 `MAX_DATE_AGE_YEARS=100`，页面明确显示该范围。2026年允许1926至2026年，包含边界。
- 仅到月份补当月01日；空值、斜线和普通非日期文本仍按既有规则置空；仅年份仍阻断。数值形式的2026.03继续按既有年月规则处理。
- 日期样式的四位整数Excel序列可正常解析；未标记日期格式的四位数字仍按仅年份规则阻断。
- 任意阻断错误返回源工作表、源Excel真实行号、字段、原值和具体原因，不加载目标模板、不生成文件。页面显示处理失败及文件未生成，无法下载此前成功处理的旧文件。
